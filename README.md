# KeepAwake

Небольшая утилита для Windows, которая запрещает автоматический переход
компьютера в спящий режим, но позволяет дисплею выключаться по обычному
таймеру Windows.

KeepAwake работает в системном трее и не изменяет схему электропитания,
реестр или системные политики.

## Возможности

- включение и выключение запрета автоматического сна;
- отдельные иконки для активного и обычного режима;
- контекстное меню в системном трее;
- переключение режима двойным щелчком;
- таймер автоматического отключения от 1 до 10 часов;
- видимый обратный отсчёт в формате `часы:минуты:секунды`;
- отображение оставшегося времени при наведении на значок;
- автоматическое снятие запрета сна после завершения таймера;
- защита от запуска нескольких экземпляров;
- работа без прав администратора;
- корректное снятие запрета сна при закрытии программы;
- журнал ошибок `KeepAwake-error.log`.

## Как это работает

KeepAwake использует Windows API:

```text
SetThreadExecutionState
```

В активном режиме устанавливаются флаги:

```text
ES_CONTINUOUS | ES_SYSTEM_REQUIRED
```

Флаг `ES_DISPLAY_REQUIRED` намеренно не используется. Поэтому:

- компьютер не засыпает автоматически;
- экран может погаснуть по обычным настройкам Windows.

## Требования

- Windows 10 или Windows 11;
- PowerShell 7;
- архитектура x64;
- права администратора не требуются.

Проверка версии PowerShell:

```powershell
pwsh --version
```

## Установка

Клонируйте репозиторий:

```powershell
git clone https://github.com/Goodvin-013/KeepAwake.git
cd KeepAwake
```

Запустите установщик:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

Программа будет установлена в:

```text
%LOCALAPPDATA%\Programs\KeepAwake
```

На рабочем столе появится ярлык `KeepAwake`.

## Использование

После запуска значок KeepAwake появится в системном трее.

### Обычный режим

Синяя иконка с луной:

- автоматический сон разрешён;
- действуют настройки электропитания Windows.

### Режим No Sleep

Зелёная иконка с молнией:

- автоматический сон системы запрещён;
- экран может отключаться;
- ручной сон, выключение и перезагрузка не блокируются.

### Таймер

В меню `Автоотключение` можно выбрать период от 1 до 10 часов.

После запуска таймера:

- режим No Sleep включается автоматически;
- оставшееся время отображается в меню;
- обратный отсчёт обновляется каждую секунду;
- по окончании времени запрет сна снимается автоматически.

Пункт `Отменить таймер` отменяет обратный отсчёт, но оставляет No Sleep
включённым без ограничения времени.

## Проверка работы

Откройте PowerShell и выполните:

```powershell
powercfg /requests
```

При включённом режиме No Sleep в разделе `SYSTEM` должен появиться процесс
`pwsh.exe`.

Раздел `DISPLAY` должен оставаться пустым — это означает, что KeepAwake
не удерживает экран включённым.

## Обновление

1. Закройте KeepAwake через меню в системном трее.
2. Получите актуальную версию репозитория:

```powershell
git pull
```

3. Повторно запустите установщик:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

Рабочие файлы в `%LOCALAPPDATA%\Programs\KeepAwake` будут обновлены.

## Удаление

Сначала закройте KeepAwake через значок в системном трее.

Затем выполните:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1
```

Будут удалены:

- установленная копия из `%LOCALAPPDATA%\Programs\KeepAwake`;
- ярлык KeepAwake с рабочего стола.

Исходный Git-репозиторий останется на месте.

```text
56 644 байта — 55,32 КиБ
```

PowerShell 7 и системные библиотеки Windows в этот размер не входят.

## Ограничения

KeepAwake не отменяет:

- ручной переход в сон;
- выключение и перезагрузку;
- действие закрытия крышки ноутбука;
- критические действия при низком заряде аккумулятора;
- обязательные корпоративные политики Windows.
