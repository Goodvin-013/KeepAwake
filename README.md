# KeepAwake

Маленькая программа для Windows, которая запрещает компьютеру автоматически
засыпать. По желанию она также не даёт выключаться экрану.

KeepAwake — это один файл `KeepAwake.exe` размером около 200 КБ. Его можно
просто запустить или поставить установщиком с ярлыком на рабочем столе.
.NET, PowerShell и права администратора не нужны. Программа живёт в системном
трее и не меняет схему электропитания и системные политики.

## Возможности

- при запуске сразу запрещает автоматический сон на 10 часов;
- включает и выключает запрет сна из меню, двойным щелчком по значку или
  сочетанием клавиш Ctrl+Alt+K (если оно не занято другой программой);
- пункт «Не выключать экран»: экран тоже не гаснет. Галочку можно поставить
  только во время запрета сна; когда запрет снимается, она тоже снимается.
  Между запусками не запоминается;
- таймеры на 30 минут, 1, 2, 3, 4, 6, 8, 10 и 20 часов, а также до
  выбранного времени, например до 18:30;
- «Продлить на 1 час»: добавляет час к идущему таймеру;
- обратный отсчёт в меню и в подсказке значка;
- версия программы в первой строке меню;
- автоматически снимает запрет, когда таймер закончился;
- защита батареи: если ноутбук работает от батареи и заряд ниже 20 %, запрет
  сна снимается, а включить его нельзя до подключения зарядки. Об этом
  сообщает уведомление. После подключения зарядки запрет нужно включить
  вручную;
- уведомления только о том, что произошло без вас: таймер закончился, села
  батарея или батарея не дала включить запрет. О ваших собственных действиях
  (включить, выключить, запустить, продлить или отменить таймер) уведомлений
  нет, состояние видно по значку;
- русский и английский интерфейс: язык берётся из Windows, его можно выбрать
  вручную в меню «Язык / Language»;
- чёткие значок и меню при любом масштабе экрана (100–250 %);
- защита от запуска второй копии;
- снимает запрет сна при любом закрытии программы.

KeepAwake не добавляется в автозагрузку.

## Установка

На странице [Releases](https://github.com/Goodvin-013/KeepAwake/releases)
есть два файла:

- **`KeepAwake-Setup-X.Y.Z.exe`** — установщик, X.Y.Z — номер версии. Ставит
  программу в `%LOCALAPPDATA%\Programs\KeepAwake`, создаёт ярлык на рабочем
  столе и добавляет удаление в «Параметры → Приложения». Права администратора
  не нужны.
- **`KeepAwake.exe`** — сама программа без установки: положите в любую папку
  и запустите.

При первом запуске Windows может показать окно SmartScreen, потому что файлы
не подписаны. Нажмите «Подробнее», затем «Выполнить в любом случае».

Удаление:

- если ставили установщиком — через «Параметры → Приложения → KeepAwake»;
  сохранённый выбор языка удаляется вместе с программой;
- если без установки — закройте программу через меню в трее и удалите exe.
  Если вы выбирали язык вручную, удалите также раздел реестра
  `HKEY_CURRENT_USER\Software\KeepAwake`.

## Использование

| Значок | Режим |
|---|---|
| Серый, закрытый глаз | Сон разрешён, действуют настройки Windows |
| Зелёный, открытый глаз | Автоматический сон запрещён |
| Синий, открытый глаз | Запрещены сон и выключение экрана |

Правый щелчок по значку открывает меню, двойной щелчок или Ctrl+Alt+K
переключает режим.

В меню «Автоотключение» выберите интервал: запрет сна включится и
автоматически выключится по окончании времени. «Продлить на 1 час» добавляет
час к идущему таймеру, без таймера пункт неактивен. «Отменить таймер»
оставляет запрет включённым без ограничения времени.

«До времени…» открывает окно, где время выбирается шагом 15 минут колёсиком
мыши, стрелками ↑↓ или кнопками справа от поля. Если выбранное время сегодня
уже прошло, запрет продлится до этого времени завтра.

## Как это работает

KeepAwake вызывает функцию Windows `SetThreadExecutionState`:

- запрет сна: `ES_CONTINUOUS | ES_SYSTEM_REQUIRED`;
- запрет сна и выключения экрана: `ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`;
- выключение: `ES_CONTINUOUS`.

Проверить работу можно командой:

```powershell
powercfg /requests
```

При включённом запрете в разделе `SYSTEM` появится `KeepAwake.exe`.
С галочкой «Не выключать экран» он появится и в разделе `DISPLAY`.

Единственное, что программа сохраняет, — язык, выбранный вручную. Он хранится
в `HKEY_CURRENT_USER\Software\KeepAwake`, значение `Language`.

## Ограничения

KeepAwake не отменяет:

- сон, который вы запускаете сами: меню «Пуск», кнопку питания, закрытие крышки;
- заставку и блокировку экрана по бездействию;
- критические действия при низком заряде аккумулятора;
- корпоративные политики Windows.

На ноутбуках с Modern Standby при работе от батареи Windows может снять
запрет через несколько минут после обычного таймаута сна.

## Сборка

Нужны CMake 3.20+ и Visual Studio 2022 (или Build Tools) с компонентом C++.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

Готовый файл: `build\Release\KeepAwake.exe`.

Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php)
после сборки exe:

```powershell
iscc /DAppVersion=2.4.0 installer\KeepAwake.iss
```

Готовый файл: `build\installer\KeepAwake-Setup-2.4.0.exe`.

Сборка через MinGW-w64 тоже поддерживается.

## Релиз

Релиз собирает GitHub Actions. Чтобы выпустить новую версию:

1. Поменяйте версию в `src/resource.h` (`KA_VERSION_*`) и в
   `src/KeepAwake.manifest`.
2. Создайте и отправьте тег с той же версией, например `v2.4.0`:

   ```powershell
   git tag v2.4.0
   git push origin v2.4.0
   ```

GitHub соберёт `KeepAwake.exe` и `KeepAwake-Setup-X.Y.Z.exe` и опубликует их
на странице Releases.
Если тег не совпадает с версией в `src/resource.h`, сборка остановится
с ошибкой.

```text
.github/workflows/      сборка и публикация релиза
```
